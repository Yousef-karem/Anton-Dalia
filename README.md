# دعوة زفاف منيرفا & زكريا

موقع دعوة زفاف عربي (RTL) بتصميم أنيق — كريمي، زيتوني، وذهبي.

## هيكل المشروع

```
wedding-invitation/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── couple.jpg      ← صورة العروسين
│   ├── music.mp3       ← أغنية الزفاف (أضفها أنت)
│   └── favicon.png
└── README.md
```

## التشغيل

افتح الملف مباشرة في المتصفح:

```bash
open index.html
```

أو شغّل خادمًا محليًا بسيطًا:

```bash
# Python
python3 -m http.server 8080

# ثم افتح: http://localhost:8080
```

## التخصيص

| العنصر | الملف | ماذا تغيّر |
|--------|--------|------------|
| الأسماء والنصوص | `index.html` | نصوص الدعوة، الأماكن، الروابط |
| تاريخ الزفاف | `script.js` | المتغير `WEDDING_DATE` |
| رابط الخريطة | `index.html` | رابط زر الموقع (`location__btn`) |
| الألوان | `style.css` | متغيرات `:root` |
| الصورة | `assets/couple.jpg` | استبدل بالصورة المطلوبة |
| الموسيقى | `assets/music.mp3` | ضع ملف MP3 بهذا الاسم |

### تاريخ العدّ التنازلي

في `script.js`:

```js
const WEDDING_DATE = new Date("2026-08-01T18:00:00");
```

عدّل التاريخ والساعة حسب موعد الحفل.

### رابط الموقع

في `index.html`، غيّر `href` لزر الموقع إلى رابط Google Maps الحقيقي لقاعة الأفراح.

## الأصول المطلوبة

- **couple.jpg** — موجودة
- **favicon.png** — موجودة
- **music.mp3** — أضف أغنية الزفاف في مجلد `assets/` باسم `music.mp3`

## المزايا

- تصميم متجاوب للموبايل أولًا
- آية قرآنية فوق صورة العروسين مع منحنى انتقالي
- بطاقة التاريخ وتفاصيل الإكليل والحفل
- زر الانتقال إلى اللوكيشن
- مشغّل موسيقى تفاعلي
- عدّ تنازلي مباشر حتى يوم الزفاف
